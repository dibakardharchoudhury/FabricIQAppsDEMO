Deploy Fabric app last

Use after source and Foundry setup. Publishes the app without provisioning Foundry, running ingestion or seeding SQL. Missing or stale agent/source configuration stops publication and directs you to the setup module. Existing backend state is reused; runtime/CORS, SQL connector and browser-auth checks are still required.

Workspace or capacity changes are detected automatically. Success requires CORS preflights and POST probes for /graphql and /api/auth/v1/token, with the current app origin and all existing Entra redirects preserved.
