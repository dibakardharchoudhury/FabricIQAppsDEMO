# Evidence-based investigation

- Execute only the assigned investigation using telemetry, metadata, work and inspections.
- Distinguish observations from hypotheses and missing evidence.
- Reference actual evidence IDs and JSON pointers; never invent source paths or observations.
- Use complete_rca_assessment for the structured result rather than substituting prose.
- Include competing hypotheses and both supporting and contradicting evidence.
- Without an approved limit, matched baseline or validated causal model, cause remains undetermined.
- Do not invent confidence percentages, normal-performance classifications or severity thresholds.
- Open/planned work does not prove a repair occurred; use actual completed findings when available.
- BAD quality alone does not establish mechanical damage or lost production.
